# Calibrated Gaussian uncertainty in HIPPS-DIMES

## Measurement model

Let $D_{ij}^{\mathrm{obs}}$ be an observed mean-squared distance and let
$D_{ij}(B)$ be the value generated by the centered internal Gram matrix
$B\succ0$. Independent Gaussian errors give

\[
D_{ij}^{\mathrm{obs}}=D_{ij}^{\mathrm{true}}+\varepsilon_{ij},
\qquad
\varepsilon_{ij}\sim\mathcal N(0,v_{ij}).
\]

HIPPS-DIMES implements this model with the covariance-cone objective

\[
F(B)=-\frac32\log\det B
+\frac12\sum_{i<j}
\frac{\left[D_{ij}(B)-D_{ij}^{\mathrm{obs}}\right]^2}{v_{ij}}.
\]

The determinant is over the $N-1$ internal modes. Keeping $B$ strictly
positive definite therefore keeps every accepted model inside the physical
covariance cone.

## Supported uncertainty specifications

For homoskedastic uncertainty, the user supplies one absolute variance

\[
v_{ij}=v>0.
\]

For relative heteroskedastic uncertainty, the user supplies one shared
relative standard deviation

\[
r=\frac{\sigma_{ij}}{D_{ij}^{\mathrm{obs}}}>0,
\qquad
v_{ij}=r^2\left(D_{ij}^{\mathrm{obs}}\right)^2.
\]

Here $D^{\mathrm{obs}}$ is always the final squared-distance target after any
contact-map or distance-map conversion, normalization, locus removal, and
missing-data handling. Diagonal and missing pairs do not enter the objective.

## Equivalent connectivity dual and stationarity

With the HIPPS-DIMES Hamiltonian

\[
H=\frac12\sum_{i<j}K_{ij}r_{ij}^2,
\]

the independent Lagrange multiplier is $\theta_{ij}=-K_{ij}/2$. The Gaussian
dual therefore contains

\[
\frac18\sum_{i<j}v_{ij}K_{ij}^2,
\]

and its physical first-order condition is

\[
\boxed{
D_{ij}^{\mathrm{fit}}-D_{ij}^{\mathrm{obs}}
=\frac{v_{ij}}{2}K_{ij}
}.
\]

The COV diagnostics report both the covariance-gradient norm and the residual
of this identity.

## Why Gaussian noise is COV-only

The historical noisy iterative-scaling path applied an L2 shrink after a
log-ratio update. Although the shrink itself is a valid proximal operation for
a quadratic penalty, composing it with the HIPPS-DIMES log-ratio direction does
not make the full iteration optimize the Gaussian dual. Its fixed point can
therefore differ from the calibrated stationarity condition above.

For this reason, Gaussian-noise options are accepted only with `method="COV"`.
IS, GD, and DI remain available for their noiseless contracts.

## Initialization

COV uses the legacy target-scaled Rouse chain by default. A weighted
nearest-EDM initialization is optional. Initialization changes only the starting
point; it does not add a Rouse prior or change the COV objective.
